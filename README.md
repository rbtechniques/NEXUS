# 🚀 NEXUS — Personal Productivity Command Center

NEXUS is a Python-based productivity application designed to help users organize their daily activities, manage tasks, track habits, write notes, and stay focused.

Built using Python, NEXUS combines multiple productivity tools into one simple command-line application.

## ✨ Features

- **Task Manager** — Create, view, and complete tasks.
- **Notes Manager** — Create, view, and delete personal notes.
- **Habit Tracker** — Track daily habits and maintain completion history.
- **Focus Timer** — Pomodoro-style focus sessions, breaks, and custom timers.
- **Dashboard** — View task progress, notes, and habit statistics.
- **Activity Log** — Keep track of important actions performed in the application.
- **CSV Export** — Export tasks, notes, and habits into CSV files.
- **Data Persistence** — Automatically save information using JSON files.
